# AI Marketing Portfolio

A professional interactive portfolio website for AI marketing, ecommerce growth, CRM optimisation, and AI workflow roles.

## How to Preview the Website

1. Open the project folder:

```bash
cd /Users/heke/Desktop/ai-portfolio
```

2. Install the website packages:

```bash
npm install
```

3. Start the local preview:

```bash
npm run dev
```

4. Open this link in your browser:

```text
http://localhost:3000
```

## Where to Edit Your Details

Most of the visible website text is in:

```text
app/page.tsx
```

Good first edits:

- Replace `your.email@example.com` with your real email.
- Replace the LinkedIn link with your profile URL.
- Replace `AI Growth Portfolio` with your name or personal brand.
- Add real project details when you have them.

## What Is Included

- Next.js app structure
- Tailwind CSS styling
- shadcn-style Button, Badge, and Card components
- Framer Motion scroll animations
- Sections for hero, projects, case studies, skills, and contact
